# Personal portfolio

A responsive React portfolio built with Vite. The interface uses Montserrat for headings and Nunito for body text.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize

Update the biography, security focus areas, and journal entries in `src/App.jsx`. The document title and description are in `index.html`.

Use **Write a post** in the journal section to add an entry and an optional cover image. Posts are saved to the current browser's `localStorage`; they are not uploaded to a server and will not automatically appear on another device or for other visitors. Connect a backend or CMS to make published posts shared across visitors and devices.
